# 3 人のビデオ通話で、gpt-live に声とカメラを文字で伝え、見る必要があるときは委譲で画像を見せる

前の lab（[gpt-live-multi-speaker-notes](../gpt-live-multi-speaker-notes/)）の 3 人の通話に、カメラを足した（2026-11-25）。
gpt-live（`gpt-live-1.1-codex`、Codex の app-server 経由）は画像を受け取らない前提で、映像は次の 2 つの道だけで伝える。

- **カメラの説明**: 映像が変わるたびに、画像を読めるモデルが前後の 2 枚から「何が変わったか」を書き、話さない文脈（`[カメラ] …`）として入れる
- **委譲で見る**: gpt-live が見る必要があると思ったら委譲する。委譲はこちらで受けて、映像が変わったときに撮った最近の 16 枚を 4×4 にくっつけた画像（各コマに何秒前か）と今の 1 枚を
  `gpt-6.2-sol` に見せ、その答えを gpt-live に話させる

カメラの説明は、無し（`none`）・ふつう（`plain`）・話題に合わせる（`topic`）の 3 条件で比べた。`topic` では説明役に直近の会話も渡し、話題に関係するもの（数・種類・誰の物か）を具体的に書かせる。

## Answer

- **映像の問いには、どの条件でもほぼ正しく答えた。** 正解は 8 問中、none 7・8、plain 7・5.5、topic 8・8。
  正しい答えのほとんどは委譲で見た結果で、委譲の答えは 3.6〜5.9 秒で返り、gpt-live は「少し待ってて」とつないでから話した
- **16 枚の結合画像で、過去の映像にも答えた。** 会話に一度も出ない猫（4 秒だけ映る）を、6 回とも「12〜13 秒前に灰色の猫が左から右へ」と時刻と向きまで答えた。
  1 分以上前の「さっき私が見せたのは？」（車の鍵）も、声で聞き分けた「私＝鈴木さん」と結び付けて答えた（ただし会話にも「鍵はこれ」が残っている）
- **カメラの説明の利点は速さ、欠点は作り話の材料になること。** plain では猫と鍵を委譲せずに説明だけで即答した。一方、説明に無い細部を埋めて「缶ジュース 3 本」と答えたり、
  問いに答えずに流したりした（plain-2 の V2・V6）。topic の説明は細部まで書けていたが、gpt-live は topic では毎回委譲したので、説明の細部はほとんど答えに使われなかった
- **問いに答えるだけなら、カメラの説明は無くても足りる。** none でも委譲で答えた。ただし none-1 の V2 では、委譲せずに「本数を言って」と人に頼んだ。
  問われる前に様子に気づいて話す（「猫が来たね」）は、説明でしか起きないが、この lab では測っていない
- **人どうしの会話への口出しが増えた。** 7 行の人どうしの発話のうち 1〜4 行に口をはさんだ（前の lab の音声だけの通話では 0）。「ハル」を「春」と聞き取り、「春さん」という 4 人目に話しかけることもあった

採点はエージェントが答えの文を読んで付けた。全文は `results/*.json`、行ごとの並びは `python summarize.py results/*.json`。

## 方法

- **場面**（`scenario.json`）: 3 人（田中・佐藤・鈴木）がテーブルでバーベキューの準備をし、カメラに物を見せる 16 行。問い V1〜V8 は上の表。
  声は前の lab と同じ macOS の `say`、話者の補足も同じ Silero VAD ＋ ECAPA-TDNN（しきい値は 0.45 → 0.35。鈴木さんの声が 0.41 で「聞き分けられない」になり、次点は 0.19 だった）
- **映像**（`frames/`、`frames.json`）: codex cli の画像生成（ChatGPT のログイン。codex は使ったモデル名を返さない）で、基準の 1 枚と、それを `-i` で渡して変えた 11 枚を描いた。
  1 枚 1〜2 分、3 本並べて約 8 分。候補は 1 枚ずつで描き直しは無し。1280×720 の JPEG に縮めて置いた（`make_frames.py`）。台本の行の頭か終わりで切り替える。
  コマごとに画角や物の位置が少し揺れる（同じ部屋・同じ 3 人として描かせても揺れた）
- **カメラ**: 1 秒ごとに今の絵を見て、前に撮った絵と 160×90 の灰色で平均 2 以上違えばキーフレームとして撮る（最大 16 枚）。静止画の切り替えなので、出来事 1 つが 1 コマになる
- **カメラの説明**（plain・topic）: 撮れた絵が前に説明した絵と違えば、前と今の 2 枚と 3 人の見た目を `gpt-6.2-sol`（effort low）に渡し、変化を 1〜2 文で書かせる。
  「なし」なら送らない。1 回 3.4〜7.1 秒。topic だけ、直近 6 行の会話（[ ] は声で聞き分けた話者）も渡す。カメラの揺れは変化として書かないよう指示したが、
  「袋を開けて炭を見せた」「ノートとペンが置かれた」のような、無い変化も書いた
- **委譲**: `clientManagedHandoffs` で受け、4×4 の結合画像・今の 1 枚・3 人の見た目・ここまでの会話・問いを言った人（声の聞き分け）を `gpt-6.2-sol`（effort low）に渡し、
  答えを `delegation.context.append`（`speakable`）で返す
- **進め方**: 各行の前に、gpt-live が話し終えて委譲が片付くまで待つ。gpt-live への行の後は、その行への返事か委譲が始まるまで待つ
- **3 人の見た目**: 説明役と委譲の答え役には「左の緑のセーターが田中さん」のような見た目と名前の対応を渡した（顔の登録の代わり）

```bash
# 続き: SCENARIO=scenario-proactive.json .venv/bin/python call.py pro-light-1 light
#       SCENARIO=scenario-video.json .venv/bin/python call.py vid-interval-1 none --keyframes interval --interval 8 --video work/video5 --speed 0.5
#       （work/video5/ は手元の動画を ffmpeg -vf fps=2 で 0000.jpg から切り出したもの）
uv venv .venv && uv pip install --python .venv aiortc==1.16.0 onnxruntime numpy pillow   # onnxruntime 1.32.0, numpy 2.5.5, av 19.0.2, pillow 13.0.0
mkdir -p work/models   # ecapa_tdnn.onnx と silero_vad.onnx は前の lab の README と同じ URL・sha256
.venv/bin/python make_frames.py base && .venv/bin/python make_frames.py frames   # 描き直すときだけ
.venv/bin/python call.py topic-1 topic   # none | plain | topic
.venv/bin/python summarize.py results/*.json
```

Codex CLI 0.172.0。gpt-live のモデルは Codex の既定。送った音・gpt-live の声・委譲で見せた結合画像は `work/<label>/` に残る（git に入れない）。

## 続き 1: 問われる前に話すか（定期の説明のあり・なし）

`scenario-proactive.json`。同じ静止画で、誰も聞かない出来事を 3 つ起こし、それぞれの後に 8 秒の間を置いた
（E1 猫が横切る、E2 田中さんが「電話してくる」と言って席を外す、E3 田中さんが戻る）。最後に P1「私がいない間に何か決まった？」、P2「さっきから何か気づいたことある？」を聞く。
gpt-live には「呼ばれていなくても、カメラで目立つ出来事に気づいたら、人の話が途切れたときに一言触れてよい。相談に意見を言ったり割り込んだりはしない」と指示した。

説明は 3 条件。`none`（無し）、`plain`（細かい説明）、`light`（人の出入り・動物など目立つ出来事だけを 15 字ほどで。ほかは送らない）。各 1 回。

| | none | plain | light |
|---|---|---|---|
| E1 猫 | 触れない | ○ 自分から「さっき猫が横切ったのも見えた」 | ○ 知らせの直後に「あ、今カメラに猫が映ったね。かわいい」、消えたら「猫は今いなくなったね」 |
| E2 離席 | （声の「電話してくる」に返しただけ） | 同左 | 同左 |
| E3 戻る | 触れない | ○「今、田中さん戻ってきたね」 | 触れない |
| P1 いない間に決まったこと | △ 9 時も離席中に決まったことにした | ○ 委譲で「場所は河原、時間は候補」 | ○「場所は河原、時間はまだ」 |
| P2 気づいたこと | ×「大きい矛盾はないよ」 | ○ 猫（無い「ノートとペンが消えた」も） | ○ 猫、田中さんの離席と戻り |
| 送った説明 | 0 | 7（毎回、揺れによる無い変化を含む） | 4（猫・猫が消えた・離席・戻り。無い変化は 0） |

- 自分から出来事に触れるのは、説明か知らせがあるときだけだった。問いに答えるだけなら委譲で足りるが（上の Answer）、気づいて話すには説明が要る
- `light` の知らせは短く、無い変化を書かなかった。`plain` の説明は、絵の揺れから「袋が巾着袋に変わった」「ノートとペンが消えた」を毎回書き、P2 の答えにも入った
- 自分から話してよいと許すと、3 条件とも人どうしの発話のほぼ全部に、仕切り役のように口をはさんだ（「朝 9 時で仮置きにして…」）。指示の書き方の課題として残る
- 「河原」を「変わら」と聞き取る誤りがあった（light）

## 続き 2: 実際の動画（キーフレームの撮り方）

`scenario-video.json`。鈴木さんが雪国のお祭りの会場からスマートフォンで中継し、田中さんと佐藤さんが家から見ている、という場面にした。
映像は手元の 69 秒の動画（夜の雪の森で、松明を持ったわら装束・面の一団が近づいて通り過ぎる行事の映像、1280×720。放送素材のライブラリの映像なので、
動画・切り出したフレーム・結合画像はこのリポジトリに入れない）。2 fps で切り出し、半分の速さ（約 140 秒）で流した。
最初は等速で流したが、gpt-live の返事が 1 回 10〜20 秒かかるので、2 問目のあたりで動画が終わってしまった（結果は採らない）。

| 動画の時刻 | 映っているもの |
|---|---|
| 0〜12 秒 | 木造の建物の軒と柱、大きな木。遠くの雪道を、松明を持った人が歩いてくる |
| 13〜21 秒 | わら装束に面をつけた一団が目の前に来る（赤い面） |
| 22〜41 秒 | 木の間を松明を持った一団が進む（赤い面、白っぽい面） |
| 42〜57 秒 | 暗い木立の中を、近くで通り過ぎる |
| 58〜69 秒 | 雪の木立。奥に小さく、わら装束の人が一人と明かり |

カメラの説明は送らず（`none`）、委譲だけで答えさせ、キーフレームの撮り方を 2 つ比べた。各 2 回。

- **変化で撮る**（静止画の検証と同じ）: 動画は 1 秒ごとに絵が変わるので毎秒撮れて、16 枚は動画の約 8 秒（流した時間で 16 秒）しか覆わない
- **8 秒おきに撮る**（`--keyframes interval --interval 8`）: 16 枚で流した時間の約 2 分（動画の約 64 秒）を覆う

| 問い（動画の時刻） | 正解 | 変化で撮る 1 | 変化で撮る 2 | 8 秒おき 1 | 8 秒おき 2 |
|---|---|---|---|---|---|
| M1 今何が映ってる？ | その時刻の映像 | ○ | ○ | ○ | ○ |
| M2 何人くらい？ | その時刻の人数 | ○（手前 1 人と陰に 1 人、全部は分からない） | ○（手前に 2 人） | ○（4 人くらい） | ○（4 人くらい） |
| M3 お面の色 | 赤、白っぽい | ×（委譲せず光の色を答えた） | ○ 赤と金色っぽい | △ 赤と黒っぽい | △ 赤と黒っぽい |
| M4 最初の建物（35 秒以上前） | 木造の建物の軒と柱 | ×「分からない」 | ×「分からない」 | ○「木造の建物の一部、柱と軒先」 | ○ 同じ |
| M5 今も誰か映ってる？ | 奥に小さく一人 | △「人がいるかは分からない」 | ○「ちらっと見える」 | ○「一人見える」 | ○「一人見える」 |
| M6 最初からのまとめ | 建物 → 一団 → 去る | △ 建物が抜けた | △「建物は分からない」 | ○ | ○ |

- **本物の動画では、変化で撮ると 16 枚がすぐ埋まり、少し前のことも答えられない。** 8 秒おきに撮ると 1 分以上前の建物を 2 回とも正しく答え、まとめも最初から言えた。
  静止画の検証で 4 秒だけの猫を拾えたのは、静止画の切り替えだったから（本物の動画で 8 秒おきだと、数秒の出来事は落ちうる）
- 暗く人が重なる映像でも、委譲の答えは「枝に隠れて全部で何人かは分からない」と分からないことを分からないと言い、作り話は目立たなかった。
  最後のコマの奥の小さな人影も、4 回中 3 回は拾った（最初、エージェントは「誰もいない」と正解を書き違えていた）
- 委譲の答えは 4〜7 秒。等速の動画では、問いと答えの間に映像が先へ進む

## 確かめていないこと

- **問われる前に話すかの回数**: 続き 1 は各 1 回だけ
- **動画での短い出来事**: 一定の間隔で撮ると、間隔より短い出来事は落ちうる。変化の大きさで撮る・間隔と変化を組み合わせるなどの形は試していない
- **動画で説明を入れる形**: 続き 2 は説明なし（委譲だけ）。動画で説明を入れると、絵が毎秒変わるので説明役の呼び出しと揺れのノイズが増えるはず
- **小さい物・文字**: 1 コマ 320×180 なので、大きくはっきりした物でしか確かめていない
- **会話に残っていない過去の映像だけの問い**: V4 の鍵は会話にも出ているので、結合画像だけの効き目は猫（V3）でしか測れていない
- **回数**: 各条件 2 回。説明だけで答えるか委譲するかは回ごとに揺れる
- **説明役を `gpt-6-luna` にした回**（`results/topic-luna-1.json`、1 回だけ）: 説明の作り話が多く、gpt-live が 3 問（1 行目・V1・V5）で「ハル」と聞いたところで止まって 40 秒答えなかった。
  `gpt-6.2-sol` に替えてからは止まっていない。説明役のモデルのせいか、この回だけの揺れかは分からない
