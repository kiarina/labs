# DualSense headroom live protocol

Before new measurements: one continuous RAW record capture and the existing synthetic video clock feed the app. Baseline AEC and headroom AEC receive the same mic/reference/event order; headroom input is rounded PCM16 x0.5, its render reference is unchanged and its output is not amplified. Only headroom is injected into the normal external track. No SDK rebuild, second microphone or alternate speaker renderer. Preserve previous binaries/source and every failed trial.

Measure exact full-scale output/decoded samples, near-full-scale counts separately, independent ETW ownership with prior positive control/lost0, all sender gates and acquisition counters. Output target is0 exact full-scale samples. Compare baseline/headroom far-only on identifiable paired intervals: normalize headroom echo transfer for intentional0.5 gain, require normalized reduction>=15dB and deterioration no greater than1dB versus baseline in both intervals. Weak coherence is inconclusive.

Known capture-only near: correlation>=.95, gain relative to intentional0.5 within+-3dB near-only, DT relative gain>=-6dB, and no more than0.5dB below same-input baseline. Report100ms window losses with the expected gain removed, not actual output gain restoration. Human near has no independent clean reference; use separate decoded DT/near/recovery clips and participant clarity>=4, no missing words/pumping and echo none/slight. Listen at original receiver loudness (common attenuation allowed, no amplification). Check raw/output clipping; do not hide failures by normalizing clips independently.

First run uses existing recorded far speech and known capture-only near, then a new human run uses no synthetic near. Quiet confirmation follows human-6: stop-voice button,8seconds silence, final4seconds measured, contrast>=6dB. OS endpoint volume/mute remain unchanged. Compare both saved DSP streams before relying on different-run human results. Physical Windows camera, other microphones/OS and long sessions remain unverified.

Short-window signed near projections use a logarithmic floor at-240dB for nonpositive gain. That floor is not a measurement of240dB voice suppression; with strong uncontrolled mic input, the absolute known-near acceptance can be invalid or fail for both profiles. Preserve the result and rely on declared separate human/relative tests, not an after-the-fact threshold change.
