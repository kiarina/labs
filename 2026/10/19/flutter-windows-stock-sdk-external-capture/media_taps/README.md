# Receiver taps used by this lab

Copied from [the media taps experiment](../../../../09/25/flutter-webrtc-media-taps/README.md) and pinned to flutter_webrtc 1.6.2+hotfix.4. This is a self-contained copy used only to observe received tracks; it is not the capture input.

The Windows receiver lookup is adapted for loopback peers with identical local and remote track IDs. Other platform behavior follows the preceding experiment. See the parent README and platform notes for measured limitations.
